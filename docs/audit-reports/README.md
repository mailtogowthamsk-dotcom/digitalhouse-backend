# Audit reports

Read-only outputs from `npm run db:audit:live` and severity summaries (PR-D).

| File | Purpose |
|------|---------|
| `live-YYYYMMDD.md` | Raw runner markdown |
| `FINDINGS-YYYYMMDD.md` | Severity + roadmap notes (**no DDL**) |

Do not treat a report as authorization to change schema. Follow [DATABASE_POLICY.md](../DATABASE_POLICY.md).
